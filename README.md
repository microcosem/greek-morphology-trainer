# Greek Morphology Trainer 🏛️

>[!TIP]
> The live site is hosted [on this GitHub Pages site](https://microcosem.github.io/greek-morphology-trainer/).

This Greek morphology trainer was created for an Elementary Greek module at Trinity College Dublin. It was created for personal study for those at the beginners level studying ancient Greek.

The site is built using GitHub Pages.

## Scope and assumptions

- The project currently includes over 50 **verbs** (no nouns or other vocab).
- This version specifically focuses on present, future, imperfect, 1st aorist, and 2nd aorist (including some "root" aorist words).

## About the files

- [`index.html`](./greek-morphology-source.html) - Source code of the study (index.html) webpage. Build with help from Claude.
- [`greek-morphology-source.csv`](./greek-verb-verblist.csv) - Contains the list of verbs and all of their related morphologies.

## How it publishes

On every push to `main`, the GitHub Action in `.github/workflows/deploy.yml` runs `build_data.py`, which checks the CSV and generates `data.js`, then deploys to GitHub Pages. If the CSV has an error, the build fails and the live site is left as it was. `data.js` is not committed.

One-time setup: **Settings -> Pages -> Source: GitHub Actions**.

## Running locally

```
python3 build_data.py          # creates data.js and reports problems
python3 -m http.server         # then open http://localhost:8000
```

### `verblist.csv`

>[!IMPORTANT]
> `verblist.csv` **is the single source of truth**. This file acts as the "raw data" that underlies the site. If you are adding or adjusting the wordlist, **edit this file only—the others are autogenerated!**

#### File rules

- There is **one column per verb**; labels are held in **column A**.
- **Rows** are found by their **labels**, so you can **reorder** rows or add verbs (columns) freely.
- Each tense has a heading row, followed by six person and number rows. If you are adding an entire column, use the prefix `No ...` or `Not ...` for forms that don't exist. (For example, if a verb does not have a 2nd aorist form, you'd follow the pattern and put `No 2nd aorist`.)
- The **Translation** row holds the English dictionary meaning.
- The **English** rows (base, 3rd person singular, past, `-ing`) are used to generate full translations, such as "We were pursuing". `English aorist (optional)` is only for aorists that are not a plain past, such as `was/were stopped`.

## Running locally

To run locally, first run the `build_data.py` script: 
 
```
python3 build_data.py          # creates `data.js` and reports problems
```

Then, launch an HTTP server locally:

```
python3 -m http.server
```

Open `http://localhost:8000` in your browser to view the built site.
